# 灵契秘仪 / Kindred Arcana 1.0.0-rc.5

首个公开发布版本，**仅授权 MaiBot「塔罗工坊」插件内使用**。牌面图像为 **AI 生成内容（GPT 生成，经人工筛选/编排/修订）**，详见 README 的 AI 生成声明。

- 78 张 800×1200 PNG，RWS-78 结构（大阿卡纳 22 + 四花色各 14）
- 固定 ASCII cardId，插件按 ID 映射抽牌与牌义
- 8=力量，11=正义；逆位仅由正位图旋转 180°
- 资源包 SHA-256 与 manifest SHA-256 见仓库 `resources.lock.json`
- 许可与署名见 `LICENSE-ARTWORK.md`、`ATTRIBUTION.md`、`RIGHTS.md`
