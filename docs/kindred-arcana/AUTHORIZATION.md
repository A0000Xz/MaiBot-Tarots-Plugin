## 1. 哪些用途需要申请

- 商业使用（收费产品/服务、广告、赞助、引流、企业内训等直接或间接盈利）

- 二次创作、改编、重绘、剪辑、拼接
- 用于训练或评测人工智能/机器学习模型
- 其他 `LICENSE-ARTWORK.md` 未明确授予的用途

插件内的个人非商业使用（下载、缓存、抽牌、查看、牌阵布局图）无需申请。

## 2. 申请方式

通过 GitHub 联系作者：<https://github.com/NethielChou>（可在本仓库开 Issue，或通过作者 GitHub 主页公开联系方式）；标题注明 **“灵契秘仪授权申请”**。

请提供以下信息：

1. 申请方身份：个人/团队/公司名称、所在地、联系方式；
2. 使用场景：产品/服务/活动名称、用途、受众、发布渠道；
3. 需要的权利：复制、发行、信息网络传播、改编、展示等（逐项说明）；
4. 使用范围：地域、期限、是否独占、是否可转授权；
5. 商业模式：是否收费、广告/赞助、预计收入或传播规模；
6. 署名方式：作者署名、版权声明、链接放置位置；
7. 是否产生衍生作品，及衍生作品的权利归属安排；
8. 其他需要说明的限制或第三方权利情况。

- 默认：**非独占、不可转授权、不可转让、有期限、限定用途**的书面许可；

- 授权自双方签署书面协议之日起生效；**口头同意、聊天中的“可以”、沉默、公开仓库可见性均不构成授权**。

## 4. 处理流程

1. 收到申请后确认材料是否完整；
2. 评估用途、范围与第三方权利风险；
3. 双方确认授权条款与费用（如适用）；
4. 签署书面协议（电子签名/盖章均可，保留签署记录）；
5. 按协议交付资源或开通使用方式；
6. 使用方按协议署名、标注与报告使用情况。

作者可基于第三方权利、品牌风险、用途合法性等原因拒绝申请。
